OWID: clean Julia build

This is the current reviewed island-layout baseline. Git tag: owid-clean-layout-baseline-v1. Open the world map. The H3-MON exports have not changed. This Julia build starts from Kontur, Natural Earth, and original OWID. All scopes are matched again. No saved layouts or assignments are read.

Checks: 54967 land tiles; exact country totals; 40 groups change tile count; all shared group borders retained. 64 internal water cells remain empty and enclosed. Gaps between separate land pieces can open to the sea. The layout has 244 groups, including the added population scopes.

Each artwork group can receive several source components. Strong child matches add source anchors but do not receive separate tile budgets. Unmatched source components join the nearest source anchor. Weak target groups share a nearby population pool. The minimum is one tile per existing G group, not one tile per old T fragment.

There are no hand-written identity overrides. Source-distance fallback is approximate. Corner-connected groups receive one budget each. Earlier edits within those groups are not inputs; Japan and New Zealand retain their original internal proportions. This reviewed baseline includes those differences. The original build audits below are unchanged. Their review flags describe the state when the files were generated. Open the fitting and export checks.

Read the images: The two tile panels share a scale. The geographic panel uses a separate scale. Colours identify the new population pools in all three panels. Labels identify G groups. Fallback target groups can share a colour. Only the selected country is shown. Empty space stays empty; no water tiles are assigned to countries.
