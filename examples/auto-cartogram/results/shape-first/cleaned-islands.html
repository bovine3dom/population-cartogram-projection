Automatic world cartograms

Review candidates, not production maps. Each represented component keeps its tile shape. There are no added connector paths. Many real land borders remain separated.

The production map has not changed. Requested tile budgets are exact; population ratios are approximate. Small islands with no tile budget remain grouped with a represented component of the same country.

These are separate trials. Position settings can differ between resolutions. The run name identifies each saved candidate.

Limits

The source contains 7,954,677,990 matched people. Unmatched population: 77,246,034. Its year is unknown. No new native-resolution population transport is approved for these layouts.

Country direction checks use main components of countries with at least 10 million people and a five-degree source separation. Island checks use a one-degree separation. These checks do not prove correct geographic positions.
