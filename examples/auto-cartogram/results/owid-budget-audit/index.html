OWID island tile budgets

Audit only. No layout, population mapping, or H3-MON export has changed.

Keep each OWID country's total tile count. Multiply that total by each source component's share of the matched Kontur population. This gives a fractional tile quota. The full CSV also gives integer budgets from the largest-remainder rule. There is no minimum island tile in this calculation.

What this means

A small local correction is useful for some countries, but it cannot make the whole OWID map population-exact by island. Start with Corsica: test moving two tiles to mainland France after assigning the remaining small components. Keep the shapes fixed elsewhere. Do not reshape Japan or Indonesia as part of this small trial.

Input checks

  • The file has 54,978 rows and 54,967 unique coordinates. Eleven coordinates have both South Africa and Lesotho labels. This inventory uses the last row, Lesotho, as the existing review loader does. The input file is unchanged. Resolve ownership before fitting.
  • Use an ISO map-unit code before a sovereign-country code. For example, Reunion is separate from metropolitan France. Otherwise its population would distort the France comparison.
  • The inventory has 205 scopes with both tiles and source population. There are 51 source scopes without tiles and three tile scopes without a direct source-code match. Some are code differences, not omitted populations: SDS/SSD, PSX/PSE, and SAH/ESH still need reviewed aliases.
  • Some source islands have no separate OWID piece. Russia and Canada each have one four-connected tile group. Connectivity alone cannot identify all source islands or exclaves.
  • Population uses native H3 centres within the source polygons. Unmatched and boundary points are excluded. The population year is not verified. OWID and Kontur scopes can differ.
  • Source and target ranks are independent. Equal colours and ranks in the panels do not establish a match. Geographic panels use longitude and latitude; they are for component identification, not area comparison. Dateline components can compress the view.
